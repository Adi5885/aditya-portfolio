# Aditya Danve — Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive dark theme, layout, and visual styling
- `script.js` — mobile navigation and scroll reveal effects
- `Aditya_resume.pdf` — resume used by the Download Resume button
- `Aditya_profile.jpg` — keep the existing profile photo from your current GitHub repository in this folder

## Run locally

Open `index.html` in a browser. Internet access is needed for Google Fonts and Font Awesome icons.

## GitHub update

Copy these files into your existing `aditya-portfolio` repository folder. Keep your existing `Aditya_profile.jpg` file in the same folder, replacing the old `index (1).html` with this `index.html` (or rename the file to `index.html`).

Then run:

```bash
git add .
git commit -m "Redesign portfolio for AI and software developer profile"
git push origin main
```

The resume button expects the file name `Aditya_resume.pdf`.
